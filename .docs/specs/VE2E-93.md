## 4. Phạm vi v1

### 4.1 Model chuẩn (`packages/domain/src/caption-style.ts`, subpath browser-safe `@lyonix/domain/caption-style`)

```ts
type CaptionPositionPreset = "top" | "middle" | "bottom";
type CaptionAnimation = "none" | "word_highlight";

/** Override (toàn video hoặc cảnh): chỉ các field khác giá trị kế thừa. */
type CaptionTextStylePatch = {
  fontId?: string;              // id trong font catalog
  fontSizePx?: number;          // px trên canvas 1080x1920, 32..128, số nguyên
  fillColor?: string;           // "#RRGGBB"
  strokeEnabled?: boolean;
  strokeColor?: string;         // "#RRGGBB"
  strokeWidthPx?: number;       // 1..20, số nguyên
  position?: CaptionPositionPreset;
  maxLines?: 1 | 2;
  animation?: CaptionAnimation;
};

/** Mặc định của template đang ghim, đã quy về đơn vị chuẩn (API tính sẵn, trả kèm TemplateSnapshotResponse). */
type CaptionTemplateDefaults = {
  fontFamily: string;           // tên font theo engine (vd. "Noto Sans CJK JP")
  fontSizePx: number;
  minFontSizePx: number;        // LyOnix tự thu nhỏ tới mức này; Creatomate = fontSizePx (không thu)
  bold: boolean;
  fillColor: string;
  highlightColor: string | null;
  stroke: { enabled: boolean; color: string; widthPx: number };
  position: { anchor: "top" | "center" | "bottom"; percent: number };
  maxLines: 1 | 2;
  animation: CaptionAnimation;
  colorCycle: string[] | null;
};

/** Kiểu chữ hiệu lực của một cảnh = mặc định template ⊕ toàn video ⊕ cảnh. */
type CaptionTextStyle = CaptionTemplateDefaults & {
  font: { id: string | null; family: string; source: "catalog" | "legacy" | "template"; supported: boolean };
  position: { preset: CaptionPositionPreset | null; anchor: "top" | "center" | "bottom"; percent: number };
  fillColorFromUser: boolean;   // D3: true thì không áp colorCycle
};
```

Helper thuần (test được, dùng chung cho UI, preview, API và cả hai renderer):

- `resolveCaptionTextStyle({ engine, defaults, global, scene })`: tính style hiệu lực.
- `applyCaptionStyleEdit(patch, field, value, inherited)`: ghi một field; giá trị bằng giá trị kế thừa thì xoá field khỏi patch.
- `clearCaptionStylePatch()`: đặt lại cảnh về toàn video, hoặc toàn video về mặc định template.
- `captionStylePatchFromOptionValues(optionValues)` và `captionStylePatchToOptionValues(patch)`: chuyển đổi với các key phẳng.
- `normalizeCaptionTextStylePatch(raw)`: bỏ field sai, không throw.
- `validateCaptionTextStylePatch(raw)`: dùng khi lưu (API).
- `captionLayoutOptions(style, engine)`: ra `CaptionStyleOptions` cho `buildCaptionAss`. Preview và render LyOnix dùng cùng hàm này.

**Mặc định hệ thống** (khi template không cho mặc định, ví dụ snapshot cũ): Noto Sans CJK JP, 64/44 px, đậm, trắng, viền đen 5 px, cách đáy 20 %, 2 dòng, không highlight (bằng `DEFAULTS` của `caption-ass.ts`, riêng `highlight` là `none`).

### 4.2 Lưu trữ

Toàn video (`optionValues`, giá trị chuỗi; `""` hoặc không có key nghĩa là kế thừa):

| Key | Patch field | Giá trị hợp lệ |
|---|---|---|
| `dynamicStyle.captionFontId` (mới) | `fontId` | id dạng `[a-z0-9-]{1,40}` |
| `dynamicStyle.captionFontFamily` (cũ, chỉ đọc) | — | như hiện nay; xem 4.7 |
| `dynamicStyle.captionFontSizePx` | `fontSizePx` | số nguyên 32..128 |
| `dynamicStyle.captionFillColor` (cũ, dùng tiếp) | `fillColor` | như hiện nay (`#RGB/#RGBA/#RRGGBB/#RRGGBBAA`); UI mới chỉ ghi `#RRGGBB` |
| `dynamicStyle.captionStrokeEnabled` | `strokeEnabled` | `true` / `false` |
| `dynamicStyle.captionStrokeColor` | `strokeColor` | `#RGB` / `#RRGGBB` |
| `dynamicStyle.captionStrokeWidthPx` | `strokeWidthPx` | số nguyên 1..20 |
| `dynamicStyle.captionPosition` | `position` | `top` / `middle` / `bottom` |
| `dynamicStyle.captionMaxLines` | `maxLines` | `1` / `2` |
| `dynamicStyle.captionAnimation` | `animation` | `none` / `word_highlight` |

Từng cảnh: thêm `captionStyleOverride?: CaptionTextStylePatch | null` vào `TimelineSceneBindingInput` và `TimelineSceneBindingResponse` (`packages/contracts`). Field này nằm trong cột Json `scenes`, nên không cần migration. Thiếu field hoặc `null` nghĩa là kế thừa toàn bộ. Field được thêm vào mọi chỗ đang liệt kê field của scene: API ghi/đọc, web `draftFromContext`/`buildTimelineSaveScenes`, domain `duplicateScene`/`splitScene`.

API chỉ kiểm tra **định dạng và giới hạn** khi lưu, không kiểm tra theo engine. Nhờ vậy, đổi template sang engine khác không làm autosave lỗi. Field không áp dụng được cho engine hiện tại sẽ được báo ở UI (4.5).

### 4.5 Ánh xạ sang renderer

LyOnix (`overlays.ts` + `caption-ass.ts`):
- font: tên fontconfig của catalog. Font cũ giữ hành vi hiện tại.
- fontSize: `fontSizePx`. Mức thu nhỏ tối thiểu là `min(recipe.minFontSizePx, fontSizePx)`, nên rule 2 dòng (thu cỡ rồi tách cue) giữ nguyên.
- fillColor: `textColor` (màu chữ chưa đọc). Màu đã đọc vẫn là `highlightColor` của recipe.
- stroke: `outlineColor` / `outlinePx`. Tắt viền thì `outlinePx = 0`.
- position: `top` → neo trên, cách 10 %; `middle` → căn giữa dọc (ASS `Alignment 5`, **nhánh mới nhỏ** trong `caption-ass.ts`); `bottom` → neo đáy, cách 20 %. Không override thì giữ đúng `placement` của recipe.
- maxLines: `maxLines`. animation: `highlight: "word" | "none"`.
- Theo cảnh: `CaptionCueInput.style` (tuỳ chọn). `buildCaptionAss` sinh thêm `Style:` (`Sub2`, `Sub3`, …) cho mỗi bộ style khác nhau. Không có style theo cue thì đầu ra **giống từng byte** hiện nay (có test fixture).
- Contract: `ComposeScene.captionParams?: Record<string, string>` (cùng key phẳng như 4.2), chỉ có khi cảnh có override. Plan cũ giữ nguyên fingerprint và job key. Danh sách font bắt buộc kiểm tra (`FONT_MISSING`) gồm mọi font hiệu lực (toàn video + từng cảnh).

Creatomate (`creatomate-dynamic.ts`, cả hai chế độ `template_scaled` và `style_only`):
- font: `font_family` = tên Creatomate của catalog. fontSize: `font_size = px/1080*100 vmin`. fillColor: `fill_color`.
- stroke: `stroke_color`; `stroke_width = 2*px/1080*100 vmin`. Stroke Creatomate vẽ ở giữa nét chữ, trong khi `outlinePx` của ASS vẽ ra ngoài; độ dày này **chưa kiểm chứng bằng render thật**, xem bằng Preview SDK. Tắt viền thì bỏ `stroke_color`/`stroke_width`.
- position: `top` → `y 10%`, `y_anchor 0%`, `y_alignment 0%`; `middle` → `50%/50%/50%`; `bottom` → `y 80%`, `y_anchor 100%`, `y_alignment 100%`.
- maxLines: `paginateCaptionBlocks(..., maxLines)`, chặn trên 2.
- animation `word_highlight`: không áp dụng, ghi cảnh báo `caption_highlight_unsupported` (UI đã khoá).
- Theo cảnh: `DynamicSceneInput.captionStyle`. Khi không có override, `source` sinh ra giống từng byte hiện nay (có test fixture).

Orshot: không đổi đường render (D4).

### 4.7 Tương thích ngược

- `dynamicStyle.captionFontFamily` (tên font tự do): giữ nguyên giá trị và hành vi render như hiện nay. Panel hiện "Font cũ: <tên> (chưa hỗ trợ trên mọi engine)" kèm cảnh báo, không tự đổi font. Key này chỉ bị xoá khi người dùng **chủ động** chọn font trong panel mới (catalog hoặc "Mặc định template"); khi đó ghi `captionFontId`.
- `captionFontId` được ưu tiên hơn `captionFontFamily` cũ.
- `dynamicStyle.captionFillColor`: dùng tiếp. `#RGB` được mở rộng thành `#RRGGBB` cho mọi engine (trước đây LyOnix bỏ qua lặng lẽ). Màu có alpha (`#RGBA`/`#RRGGBBAA`, UI chưa từng sinh ra) giữ nguyên trong dữ liệu, Creatomate áp như trước, LyOnix không áp như trước; panel hiện cảnh báo.
- Rule validate của key cũ không đổi. Font cũ lạ không bao giờ làm autosave lỗi.
- Cảnh cũ không có `captionStyleOverride` thì kế thừa toàn bộ. Dữ liệu override hỏng khi đọc được chuẩn hoá (bỏ field sai), không làm Studio hay API lỗi.
- Web gửi lại nguyên `optionValues`, nên key không bị đụng tới vẫn được giữ.

### 4.9 Autosave / undo

- Slider và bộ chọn màu cập nhật preview qua state cục bộ. Chỉ ghi vào draft (`mutate`) **một lần** khi thả chuột/phím (`pointerup`, `change`, blur, Enter).
- Một thao tác ứng với một mục undo. Autosave debounce 1,2 s như hiện tại.
- Không đổi versioning, approve, draft: mọi chỉnh sửa tạo version `draft` mới và phải duyệt lại trước khi render (rule hiện có).
