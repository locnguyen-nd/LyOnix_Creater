## Giới hạn trung thực (3 test fail đều là lỗi harness chỉ xảy ra trên Windows — XANH trên CI Linux)

1. `@lyonix/providers` → `src/template-lint.test.ts` → "template:lint CLI ... exits 2 on unreadable JSON" (1 test).
   Nguyên nhân: test `spawnSync` shim `node_modules/.bin/tsx` (không đuôi mở rộng). Trên Windows shim này không chạy
   trực tiếp → `spawnSync ... tsx ENOENT`, `status=null` (test kỳ vọng `0`). Trên Linux CI shim là file thực thi → PASS.
   KHÔNG sửa (code VE2E-117, ngoài scope hẹp; CI Linux đã xanh).

2. `@lyonix/media-worker` → `src/parity/parity.test.ts` → "render:parity CLI on real videos" (3 test).
   Nguyên nhân: fixture `src/compose/test-fixtures.ts` dựng video bằng FFmpeg `drawtext` với
   `fontfile=C:/Windows/Fonts/arialbd.ttf`. Dấu `:` của ổ đĩa (C:) phá cú pháp filtergraph FFmpeg trên Windows
   ("No option name near '/Windows/Fonts/arialbd.ttf:text=One...'"). Trên Linux CI font ở `/usr/share/fonts/...`
   (không có `:` ổ đĩa) → PASS. KHÔNG sửa (code VE2E-116, ngoài scope hẹp; CI Linux đã xanh).

3. `frame.extract (VE2E-30)` từng fail 1 lần (flaky byte-cap) nhưng PASS khi chạy lại — không tái hiện ổn định.
